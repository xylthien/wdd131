Final Project Planning

  1. Site Name

    The Adventurer's Codex

    I chose this because every Adventure begins somewhere. This codex will be the perfect place to start!

  2. Site Purpose

    As character creation is the most stressful and complicated part of Dungeons and Dragons, this codex aims to alleviate most, if not all, of those complications. The goal is to streamline the process so that anyone of any skill level will be able to create a character easily.

  3. Scenarios

    • What class should I choose for my first character?
    • What abilities or skills should I choose for my character?
    • How do I calculate ability scores?
    • Which equipment should I choose to start with?
